设备联邦的设计阶段已完成：24 条 ADR 覆盖入网、协作、执行、安全与网络。实现状态见 STATUS。

## 核心原则

1. **成员制**：同账号 + 都装插件 + 显式入网才互通；账号只做成员校验与隔离。
2. **资源所有者原则**：谁能碰文件/执行代码，由那台设备配置与审批决定（Tool Policy、执行上下文、审批收件箱）。
3. **两条通道**：直调（无 Room、无对话上下文）与协作（Room，共享 Board、共享对话记录）。
4. **按需唤醒**：只有被点名或被分配任务块的 agent 才启动；其余不跑模型。
5. **动静分离**：稳定成员信息进 prompt，在线状态/任务细节进工具结果与 Board，保护 KV cache。
6. **严格同版本**：v1 宁可拒绝连接，也不接受"能连但行为不一致"。

## 待实现（按依赖顺序）

1. **Host 插件接入**：`$DSH_HOME` 身份/邀请/Fleet 配置持久化；`FleetNode` 挂 Cordis；账号指纹注入；握手补 `pluginVersion`/`dshVersion`/`capabilities`。

5. **UI**：设备页/配对/审批收件箱/房间视图/Room 设置；打成可安装 bundle。
