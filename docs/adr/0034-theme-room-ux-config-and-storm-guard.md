# ADR-0034：主题适配、Room 交互完善与配置页迁入

- **状态**：已实现（2026-11-15，1.15.0）
- **相关**：ADR-0033（命名/UI）、ADR-0025（Room）
- **结论**：控制台跟随 DSH 主题；Room 收件人、@ 提及、任务负责人可操作；配置页迁入“设备联邦 → 配置”；归档恢复自动重邀远端；半开连接风暴加保护。

## 1. 主题

- 移除硬编码白色/深色层，改用 DSH 语义变量（`--dsw-alias-*`）与中性灰；浅色/深色主题共享同一套样式。
- 全局 hover/focus/active、细滚动条、卡片层次。

## 2. Room 交互

- 发消息：成员改为可点击头像 chip，支持全选/清空；默认收件人仍为参与者。
- @ 提及：输入 `@` 出现成员建议（显示名），Tab/Enter 补全；发送时自动把被提及成员加入 `to`。
- 任务：每条任务可改状态与负责人（owner），owner 必须是房间成员；新增任务仍可选任意成员。

## 3. 配置页

- 设备联邦新增“配置”标签，读取/保存 `/device-fleet/config`，等价于原插件配置页；保存按 top-level diff 提交，即时生效。
- 1.16.1 起移除 Settings → Plugins 的 Fleet 配置页注册与组件，避免重复入口；服务端 schema 保留用于 profile config 兼容。

## 4. 归档恢复自动重邀

- `room_restore` 后对每个 remote 成员调用其 `room.join`（优先复用 `remoteSessionId`）；若产生新 session，替换旧成员。
- 失败只记录 `reinviteFailed`，不阻塞恢复。

## 5. 连接风暴保护

- FleetNode 跟踪未完成握手的 socket，最多 256 个；direct server `maxConnections=256`；close 时销毁全部 pending socket。
- 避免对端重连风暴把进程 fd/端口耗尽（真机观察到 3k+ 半开连接）。

## 不变量

1. 主题仅影响展示，不改变配置/协议。
2. `@` 补全使用成员名插入，收件人只允许房间成员。
3. 配置保存只提交变化的 top-level 段。
4. 自动重邀失败不阻止 Room 恢复。
5. 连接上限只影响异常风暴，不限制正常 peer 数（正常远小于 256）。

## 未完成

- 控制台 i18n 已覆盖静态/动态文案与原生确认框；插件日志/工具原始错误仍未翻译；
- P2P（范围外）。
