# 使用显式入网，而不是"同账号自动互联"

## Status
accepted

## Context
DSH 运行时没有"账号 → 设备目录"或"验证对端账号"的端点；插件只能在本机读到自己登录的账号 ID。仅凭"同账号 + 都装插件"无法发现对端，也无法证明对端身份；要实现零配置自动互联必须引入服务端协调。

## Decision
采用显式的 Fleet 入网：首台设备创建 Fleet 并签发一次性邀请，其他设备接受邀请后成为成员；账号身份只作为成员校验与隔离条件（账号指纹比对、切换账号即断连），不作为发现或传输通道。

## Considered Options
- 零配置自动互联（需自建或官方服务端做账号-设备绑定）——一期成本与运维/隐私面过大，否决。
- 局域网内自动出现"待确认设备"、点击确认后入网——作为未来可选增强保留。

## Consequences
一期无需服务端；跨网络发现需要会合点（Hub 设备或 Relay）；同账号但未入网的设备不会被自动接纳。
